# Adaptive Poker Study — Android v0.6.0

Мобильное приложение для **послесессионного анализа завершённых раздач и GTO-тренировки**. Данные хранятся локально на устройстве. Приложение не читает экран покерного клиента, не показывает подсказки во время игры и не интегрируется с игровым столом.

## Что есть в этой версии

- Импорт GGPoker Hand History в TXT и ZIP через системный выбор файлов Android.
- Парсер и разбиение решений Hero по улицам.
- Префлоп-справочник generic MTT chip-EV с диапазонами 5/10/20/40/100 BB (загружается отдельным действием из открытого репозитория).
- Учебные случайные префлоп-споты и показ смешанных частот.
- Импорт оригинального JSON-дерева TexasSolver (`action_node`, вложенный `strategy.strategy`, ветки `dealcards`), индекс узлов, выбор конкретной комбинации и добавление стратегии в локальную библиотеку.
- Экспорт CSV и JSON-бэкапа.
- Хранение в IndexedDB внутри Android WebView; после первоначальной загрузки диапазонов базовые функции работают офлайн.

## Важные ограничения стратегии

1. Публичные MTT-диапазоны — reference для generic chip-EV. Они не являются решением конкретного PKO-турнира.
2. ICM и баунти-эквити сейчас не рассчитываются.
3. TexasSolver не встроен в APK и не запускает тяжёлые solve-задачи на телефоне. Приложение импортирует готовый JSON-результат и помогает сопоставить точную комбинацию и узел.
4. Совпадение частоты выбранного действия не равно потере EV. В этой версии EV-векторы TexasSolver сохраняются только как исходные значения с неустановленной шкалой; EV loss в BB намеренно не рассчитывается.
5. Размеры BET/RAISE из TexasSolver могут быть заданы в абсолютных единицах исходного solve. Пока единицы и размер банка не подтверждены, приложение не переводит их автоматически в проценты и не обещает совпадение сайзинга.
6. При выборе узла приложение отсекает комбинации, конфликтующие с доской и раскрытыми картами ветви, но пользователь должен вручную проверить линию действий и улицу.
7. Если ситуация/узел не распознаны однозначно, приложение оставляет её без GTO-оценки.

## Сборка APK без собственного компьютера

В проект включён GitHub Actions workflow: `.github/workflows/build-android-apk.yml`.

1. Создай приватный репозиторий GitHub с именем `AdaptivePokerStudy`, ветка по умолчанию — `main`. При создании включи **Add a README file**, чтобы у репозитория появилась ветка. `.gitignore` и license добавлять не нужно.
2. Пришли ссылку на репозиторий. Я загружу в него файлы проекта; если GitHub запросит дополнительные разрешения на запись, их нужно будет подтвердить.
3. После добавления workflow в `main` GitHub автоматически запустит **Build Android APK**. Вручную запускать workflow не требуется.
4. После успешного завершения открой вкладку **Actions**, выбери последний запуск, раздел **Artifacts**, скачай `AdaptivePokerStudy-debug-apk` и распакуй архив.
5. Открой `app-debug.apk` на Android и подтверди установку из этого источника.

Workflow использует JDK 17, Android SDK API 37 / Build Tools 36 и Gradle 9.6.0 — это соответствует таблице совместимости Android Gradle Plugin 9.5.0.

**Этот исходный ZIP не содержит APK.** APK должен быть собран workflow в GitHub Actions. В среде подготовки не было Android SDK/Gradle build toolchain, поэтому я не буду заявлять, что APK собран или проверен на устройстве.

## Локальная сборка

Нужны JDK 17, Android SDK Platform 37, Build Tools 36.0.0 и Gradle 9.6.0. Из корня проекта:

```bash
gradle --no-daemon assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверки

Проверено в среде подготовки:

- `node --check app/src/main/assets/app.js`;
- `node tests/mobile-core.test.js`;
- импорт исходной пользовательской выгрузки: 165 раздач и 254 решения Hero;
- количество решений по улицам: preflop 170, flop 49, turn 27, river 8;
- spot_key Android/JS совпали с предыдущим Python-экспортом по всем 254 из 254 решений.

Не проверено в этой среде: сборка APK, реальный запуск на Android-устройстве, работа SAF на разных оболочках производителей и прогон TexasSolver на телефоне.

## Структура

- `app/src/main/java/.../MainActivity.java` — Android-оболочка, SAF импорт/экспорт, загрузка диапазонов.
- `app/src/main/assets/` — локальный интерфейс и аналитическое ядро.
- `tests/` — Node.js smoke tests для аналитического ядра.
- `.github/workflows/` — облачная сборка APK.
